# V3.7 "First impression" plan

After cf7a271. Owner-approved 2026-10-19: Archivo Expanded caps for the name, dollars and approximate user counts, the VyaparDrishti repo stays unlinked (it is private: GitHub returns 404), and the first load must feel fast and polished.

## Measured baseline (production build, Playwright + CDP)
| Profile | FCP | LCP | CLS | Long tasks | Fonts done |
|---|---|---|---|---|---|
| Desktop 1440, no throttle | 560 ms | 560 ms | 0 | 147 ms | 168 ms |
| Mobile 375, 4G 1.6 Mbps/150 ms, CPU x4 | 1484 ms | 1484 ms | **0.151** | **343 ms**, 128, 120, 110 | **~1950 ms** |

- The layout shift is from web fonts arriving after first paint: the H1 and hero diagram jump 24 to 26 px at about 2.1 s. A smaller shift comes from HeroSheet switching wide to compact in a `useEffect` (matchMedia).
- The entrance is four separate beats: name, then the H1 word by word over about 1 s, then the lead at 700 ms, then the CTA at 850 ms. The CTA arrives last.
- No fonts are preloaded. The main chunk is 116 KB gzipped and includes the command palette (cmdk + dialog), which is only needed on Ctrl K.

## Changes
1. **Display font.** Archivo, weight 800, width 125%. It is a static instance subset to Latin and self-hosted as `src/assets/fonts/archivo-expanded-800-latin.woff2` (10.6 KB, built with fontTools from `@fontsource-variable/archivo`, a devDependency). It replaces Instrument Serif everywhere (21 KB). The hero name is caps.
2. **Metric-matched fallbacks.** These come from fontTools against Arial.
   - Space Grotesk 500 vs Arial: size-adjust 110.3%, ascent 89.2%, descent 26.5%, line gap 0%.
   - Archivo 800 wdth 125 vs Arial Bold: size-adjust 129.3%, ascent 67.9%, descent 16.2%, line gap 0%.
3. **Preload.** `prerender.mjs` injects `<link rel="preload" as="font" type="font/woff2" crossorigin>` for the Archivo subset and the Space Grotesk Latin woff2 into every page.
4. **Entrance choreography.** One sequence, done by about 1 s:
   - Name lines rise at 0 and 90 ms (750 ms each).
   - H1 words at 180 ms plus 28 ms per word (650 ms each).
   - Lead at 280 ms. CTAs at 360 ms. Sheet details at 450 ms.
5. **Mobile diagram.** HeroSheet and SystemArchitecture render both variants and pick with CSS (`hidden md:block` / `md:hidden`). No matchMedia state.
6. **Lazy command palette.** It loads on the first Ctrl K or header click and opens immediately.
7. **Copy.**
   - S-02 cost `~Rs 3,000` becomes `~$35` (about Rs 86 per dollar).
   - S-04 users `~9,000` becomes `9K+`.
   - The S-04 tl;dr "used by about 9,000 active users" becomes "used by 9K+ active users".

## Targets (tested)
- Mobile 4G CLS below 0.05.
- Hero actions start animating within 400 ms.
- The last H1 word starts within 450 ms.
- The font file is under 16 KB.
- No Instrument Serif left anywhere.
- Fonts are preloaded.
- The compact hero diagram is chosen by CSS without JS.

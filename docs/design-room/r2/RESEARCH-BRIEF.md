## The site we are improving (read it, do not copy it)

harshallade.site is a dark, mono-and-sans developer portfolio for Harshal Lade, a software engineer (AI and data platforms, Mumbai) looking for AI/data-platform roles at startups. Concept "Dataflow": the page is one architecture diagram. Current sections: Hero (blueprint-style sheet with an animated architecture graph, drawing index, word-by-word headline), Metrics strip, Systems (five generic architecture diagrams, one row each), Work (3 project rows), Log (experience timeline), Stack (tool groups), Contact (email + copy button), footer. Motion: CSS entrance, Lenis smooth scroll, GSAP scroll reveals, progress line, page-wide left "bus rail".
Constraints: one accent colour (lime #C6FF3D) on near-black; fonts Space Grotesk and JetBrains Mono; no particles, preloader, custom cursor, scroll-jacking, gradient text or glassmorphism; no invented metrics; employer details are deliberately generic; mobile first; reduced-motion respected; a low-memory machine, so no heavy WebGL.
Read for context if useful: `../../V3-CONTROL-ROOM.md`, `../DESIGN-FINAL.md`, `../../MOTION-PLAN.md`.

## What to produce

Write ONE markdown file (path given in your instruction), at most ~1,500 words. For every item: name, URL you actually opened, what is distinctive (one or two sentences), and the specific technique (layout, motion, typography, interaction, content structure), plus how it could translate to this site's sections (Hero, Metrics, Systems, Work, Log, Stack, Contact, Footer, transitions).

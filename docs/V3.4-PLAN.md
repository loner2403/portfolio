## Specs

**D1 How I build** (`Principles.tsx`)
- Wrapper: `data-reveal`, `mt-20`. Keep the `HOW I BUILD` label as the `h3`.
- The list becomes an `ol` with `border-t border-line`. Each `li` has `data-testid="principle"`, `border-b border-line py-6`.
- Grid columns:
  - Below lg: `grid-cols-[3.5rem_minmax(0,1fr)]`.
  - lg and up: `lg:grid-cols-[4rem_minmax(0,16rem)_minmax(0,1fr)_auto] lg:items-baseline lg:gap-x-8`.
- Cells, in order:
  1. Number: `font-display text-4xl leading-none tabular-nums text-card-1`.
  2. Title: `text-lg font-medium text-ink`.
  3. Line: `text-sm leading-relaxed text-muted max-w-[60ch]`. Below lg it sits under the title, `col-start-2`.
  4. Seen-in: `font-mono text-xs text-faint`, then links. Each link is `inline-flex min-h-11 items-center hover:text-ink underline-offset-4 hover:underline`, separated by `, `. Below lg it is `col-start-2`.
- This is a quiet section: no colour fills.

**D2 404** (`NotFound.tsx`)
- `<section data-testid="not-found" className="tone-ink bg-card-3 py-24 md:py-36">` with Container.
- Content, top to bottom:
  - `label`: `404`.
  - h1 `font-display font-normal leading-[0.95] text-balance text-[clamp(3rem,9vw,8rem)] text-ink`, reading `This page is not in the graph.`
  - p `mt-6 max-w-[48ch] text-lg text-ink`, reading `The link may be old or mistyped. Try one of these instead.`
  - A link list `mt-10 flex flex-col gap-1 border-t border-line pt-6`:
    - `← Back home` to `/`.
    - Each project: `Link` to `/projects/:slug` showing the title.
    - Each link is `inline-flex min-h-11 items-center font-mono text-sm text-ink underline-offset-4 hover:underline`.
- Keep `useDocumentMeta`. Coral `#FF8A65` with `#14110F` ink is about 8:1.

**D3 Header** (`SiteHeader.tsx`)
- `HeaderLink` gains `variant?: 'bar' | 'sheet'`. `bar` is today's classes.
- `sheet` classes are `flex min-h-14 items-center border-b border-line font-display text-[2.25rem] leading-none text-ink`. No marker.
- The mobile menu `nav` uses `sheet` with `py-2`.
- The toggle button label reads `Close` when open and `Menu` when closed. `aria-label="Toggle menu"` and `aria-expanded` stay.
- `Ctrl K` and the toggle become `min-h-11 min-w-11 md:min-h-8 md:min-w-0`, so they stay 44px on mobile and are lighter on desktop.

**D4 Systems dim** (`Systems.tsx`, `scroll-layer.ts`)
- Each `article.stack-card` gets a LAST child: `<span aria-hidden="true" data-stack-dim className="pointer-events-none absolute inset-0 rounded-sm bg-bg opacity-0" />`.
- In the existing `.stack-card` loop in `scroll-layer.ts` (the `(prefers-reduced-motion: no-preference) and (min-width: 1024px)` block), add a second tween for each card that has a `next` card. It runs `card.querySelector('[data-stack-dim]')` from opacity 0 to 0.45, with the same scrollTrigger settings as the scale tween (`trigger: next`, `start: 'top 85%'`, `end: 'top 25%'`, `scrub: 0.3`, `invalidateOnRefresh: true`).
- Opacity only. The last card never dims. Reduced motion and mobile never run it.

## Review amendments (Sonnet design+eng review, 2026-10-19; Codex auth still broken, so subagent-only)

These override the specs above.
- **D3 header variants:** branch the full class string per variant; never append. Every class is a literal.
- **D3 toggle button:** remove `aria-label` so the accessible name is the visible `Menu`/`Close` (WCAG 2.5.3). Keep `aria-expanded` and `aria-controls`. Close the menu when the route `pathname` changes.
- **D4 timeline:** one GSAP timeline per covered card with a single scrollTrigger. The timeline holds the existing scale tween and the dim tween at position 0. This replaces both separate tweens.
- **D4 overlay:**
  - Classes: `-inset-px rounded-sm bg-signal-ink`.
  - Animate opacity to 0.35, not 0.45, so the warm colours don't go muddy.
  - The overlay must be the article's last child.
- **D1 seen-in:** keep the visible `seen in` prefix. Links use `hover:text-signal` (unchanged) and `[@media(pointer:coarse)]:min-h-11 inline-flex items-center`, so desktop rows don't inflate.
- **D2 links:** underlined by default (`underline underline-offset-4`). The `←` goes in `<span aria-hidden="true">`.
- **Tests:**
  - The dim test uses `expect.poll`, and checks that S-01 starts at 0.
  - Button selectors use the visible names.
  - The 404 h1 check is scoped to `main`.
- **Accepted, not fixed:** no scroll lock or focus return in the mobile menu, and the 404 is a soft 404 (HTTP 200, `noindex`).
